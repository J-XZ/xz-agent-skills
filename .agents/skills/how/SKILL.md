# 代码如何工作

直接只读调查并回答，不修改文件、不构建或运行测试。

1. 确定目标功能、文件或模块；范围不明且影响调查时才提问。
2. 用文件读取、搜索及必要的只读命令定位入口、调用点和相关文档。
3. 沿目标路径说明输入、关键处理、输出及副作用；按需补充状态归属、异步和错误路径。
4. 用实际读过的文件位置支持关键结论，区分源码可确认的行为、依赖配置的行为和未知项。

先简短回答，再按需列出流程和代码位置。结论限于静态阅读所得。涉及职责调整时给出有依据的建议，由用户决定是否实施。
