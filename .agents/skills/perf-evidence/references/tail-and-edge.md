# 尾部延迟与边缘场景

目标涉及分位数、超时、冷启动、倾斜、故障或资源压力时使用；只选择相关指标和场景。

## 指标与样本

- 明确目标分位数或 SLO，只报告相关分位数，并附样本数、时长、分布、波动及错误率。
- `N × (1-q)` 只粗略估计分位数以上的样本量；结合时间相关性、分辨率和多轮波动判断样本是否足够。
- 分位数尾样本与超过 SLO 的请求不同；零违规也需说明不确定性。
- `max` 只代表本次观测。总体分位数由合并后的原始样本或兼容直方图计算。
- 区分客户端总延迟、服务端排队、执行、下游等待和重试；端到端分位数直接测量。
- 说明开环或闭环负载及实际到达率；闭环负载会因慢响应降低发压。统计时包含漏发、拒绝和失败请求。

## 最小实验

| 机制 | 对照 |
| --- | --- |
| 排队与饱和 | 实际运行点和邻近负载点的队列、利用率与尾部 |
| 突发与热点 | 代表性倾斜输入下的慢请求分布与最热实例 |
| 后台任务与 GC | 任务时间线、停顿与慢请求；仅相关性不足时加控制实验 |
| 冷启动 | 首批请求与稳态分开，记录预热条件 |
| 输入或资源边界 | 目标边界下的延迟、内存、错误率和正确性 |
| 故障与恢复 | 授权隔离环境中故障前、中、后及恢复状态 |
| 累积问题 | 有泄漏或周期证据时限定时长长跑，预先设停止条件 |

一次只改变必要变量，每个场景单独建立基线。未测场景明确标注，局部退化单独报告。

## 收益估计

- 受影响比例乘单次节省只估计均值贡献，p99 收益需逐请求数据或有依据的排队模型，并说明调度、相关性和到达过程的假设。
- 控制实验的分位数位移只是预估，实际收益在实施后验证。
- 收益只归于受影响的请求；无退化结论限于已测场景。
