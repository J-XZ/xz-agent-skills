# 实验环境操作规范

在实验平台服务器上工作时始终适用，子代理同样遵守；平台有更严格的规定时同时遵守。

1. 仅用于科研或教学实验，不用于非法或商业用途；不共享账号，不绕过审计或空闲检测，不攻击基础设施。
2. 远程登录使用 SSH。服务不绑定公网可达地址；单机通信使用回环，节点间通信和大流量使用平台指定的实验网。
3. 无法确定哪个地址属于实验网时，暂停相关网络操作并询问；没有实验网时停止依赖它的操作。
4. 不扫描公网，不运行长期公网服务，不对公网进行高并发传输。
5. 控制网上传下载总速率不超过 **20 MB/s**，多个并行传输合计。单个传输留余量可用 `scp -l 128000`（Kbit/s）或 `rsync --bwlimit=15625`（KiB/s），均约 16 MB/s。
6. 不读写 `/proj`；不修改控制网接口，不在控制网上广播或组播。
7. 不存储或传输受隐私法规保护的数据。
8. 挂载 SSD、格式化磁盘或文件系统、重启设备，均须用户明确许可。

执行前确认目标设备、网络和文件归属；无法满足规则时停下并说明具体阻塞。
